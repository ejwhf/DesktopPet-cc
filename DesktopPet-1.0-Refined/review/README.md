# Review assets

`blink/` is the currently approved blink package for `idle.alt.png`.

It contains the four authored states, continuous samples, layered source material,
animation previews, build scripts, and validation reports for the BD-axis eyelid rig.

Earlier experiments are excluded from Git. Local copies, when present, are kept in
the ignored `_local-archive/` directory so they remain recoverable without cluttering
the branch or GitHub.

The legacy files under `assets/natural-motion/rigs/idle/` are runtime dependencies of
the existing application code. They remain until the approved package is integrated
into the runtime in a separate change.
